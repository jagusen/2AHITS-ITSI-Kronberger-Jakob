### Übung 3.2

1. Zuerst musst du mit `curl -O` die Datei `goethe.txt` downloaden
-> Eingabe 
```sh
$ curl -O https://www.franzmatejka.at/htl/doc/ITSI_2/05_hashing_encoding/data/goethe.txt
```

2. Danach musst du den SHA-256 Hashwert der in der Datei steht in Hex umwandeln mit der openssl Funktion dgst
-> Eingabe
```sh
$ openssl dgst -sha256 -hex goethe.txt
```
-> Ausgabe
```
SHA2-256(goethe.txt)= a911a35ff92bcd4250c063a0547dae3f1ba2b839eaf12b64c955cf3ff7e570e0
```
