## 3. Schritt

### Erste Schritte im Kali Linux

-> Vs Code Installation

- wget -O vscode.deb "https://code.visualstudio.com/sha/download?build=stable&os=linux-deb-x64"

- sudo apt install ./vscode.deb

- code --version

-> VS code starten mit: `code .` (Davor mit `cd 2AHITS-ITSI-Kronberger-Jakob` Ordner wechseln)


-> Mit GitHub verbinden:

- git config --global user.name "Vorname + Nachname"

- git config --global user.email "deine@email.at"

- git clone <Repo link von GitHub>

- Tastaturlayout ändern: `setxkbmap de` 
- Herunterfahren: `sudo shutdown -h`
- Passwort und Username für Kali-Linux: `kali`

## 4. Schritt

-> Erste Befehle in Metasploitable
