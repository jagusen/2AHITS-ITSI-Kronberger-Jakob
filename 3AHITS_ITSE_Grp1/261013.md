## 3.Schritt

### Erste Schritte im Kali Linux

-> Mit GitHub verbinden:

- git config --global user.name "Vorname + Nachname"

- git config --global user.email "deine@email.at"

- git clone <GitHub Repo Link>

-> Mit folgenden Befehlen kannst du dann jederzeit ins GitHub wieder wechseln 

Eingabe: 
```sh 
ls
```
Ausgabe: 
```sh
2AHITS-ITSI-Kronberger-Jakob  Documents  Music     Public     Videos
Desktop                       Downloads  Pictures  Templates
```
Danach wechselst du in `2AHITS-ITSI-Kronberger-Jakob` mit: 

```sh
cd 2AHITS-ITSI-Kronberger-Jakob
```

Im Anschluss führst du folgenden Befehl aus um ins GitHub zu laden: 

```sh
code
```

- Tastaturlayout ändern: `setxkbmap de` 
- Herunterfahren: `sudo shutdown -h`
- Passwort und Username für Kali-Linux: `kali`

## 4. Schritt

-> Erste Befehle in Metasploitable

- Für User und Passwort gibst du folgendes ein: `msfadmin`
- Mit `sudo loadkeys de` stellst du deine Tastatureinstellungen auf Deutsch
- `sudo shutdown -h` = herunterfahren



-> Wenn du deine IP Adresse wissen möchtest führst du folgenden Befehl aus: 
```sh
ifconfig
```
