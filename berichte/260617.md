# 1. Der Befehl xxd

`xxd` zeigt den Inhalt von Dateien oder Texteingaben als **Hexadezimalwerte** an.

Beispiel:

```sh
echo "a" | xxd
```

Ausgabe:

```sh
00000000: 610a  a.
```

### Erklärung

- `61` = Hexadezimalwert für den Buchstaben **a**
- `0a` = Zeilenumbruch (Enter)
-  `echo` fügt  am Ende einen Zeilenumbruch hinzu.

Deshalb entstehen zwei Bytes:

| Zeichen       | Hex 
| ------------- | --- 
| a             | 61  
| Zeilenumbruch | 0a  



# 2. Pipe |



```sh
echo "abcde" | xxd
```

Die Pipe leitet die Ausgabe des ersten Befehls als Eingabe an den zweiten weiter.

Ablauf:

   xxd → zeigt Hex-Werte

# 4. Eine Datei mit xxd anzeigen

```sh
xxd klassenkassa.csv
```

Hier wird die komplette CSV-Datei byteweise angezeigt.

Eine Zeile sieht so aus:

```sh

```

Umgerechnet:

```sh
M  a  x  i  m  i  l  i  a  n
```

also:

```sh
Maximilian
```

### Aufbau einer xxd-Zeile

Beispiel:

```sh
00000000: 4d61 7869 6d69 6c69 616e  Maximilian
```

Links:

```text
00000000
```

= Speicherposition (Offset)

Mitte:

```sh
4d61 7869 ...
```

= Hexadezimalwerte

Rechts:

```sh
Maximilian
```

= lesbare ASCII-Darstellung

# 9. Option `-p`

```sh
echo -n "😃 " | xxd -p
```

Ausgabe:

```sh
f09f988320
```

`-p` bedeutet:

**Plain Hex Dump**

Es werden nur die Hex-Zahlen ausgegeben:

* keine Adressen
* keine Textspalte



# 10. Hex zurück in Text umwandeln



## Mit `-r -p`

```sh
echo -n "61" | xxd -r -p
```

Ausgabe:

```sh
a
```

### Erklärung

* `-r` = reverse (rückwärts)
* `-p` = Plain-Hex-Format lesen

Hex:

```sh
61
```

wird zurückverwandelt in:

```sh
a
```

- Mit xxd:

Du benötigst das Werkzeug `-b` um die Bytes in Binärdarstellung zu zeigen

Eingabe: 
```sh
echo -n "abc" | xxd -b
```

Ausgabe: 
```sh
01100001 01100010 01100011                             
```

`01100001 -> a`

`01100010 -> b`

`01100011 -> c`

- Mit hexdump


Eingabe:
```sh
echo -n "abc" | hexdump -v -e '1/1 "%08b\n"'
```

Ausgabe: 
```sh
01100001 01100010 01100011 
```

- Octet

Der Begriff `Octet` bedeutet konkret eine Folge von 8 Bits 

-> 1 Octet = 8 Bits 

Der Begriff wird vorallem in der Netzwerktechnik verwendet um genau festzulegen dass es sich um genau 8 Bits handelt. 

- Funktion -E

Die Option -E von xxd bewirkt, dass die rechte Textspalte (die ASCII-Darstellung) in EBCDIC statt in ASCII interpretiert und dargestellt wird.

### Ist es noch relevant ? 

Nein. -E wird grundlegend nur noch benötigt wenn du Binärdatein untersuchst die EBCDIC-kodierten Text enthalten und du diese entschlüsseln möchtest. 











- Um einen dezimalen Wert (ASCII Ziffern) als Binärwert in ein File zu schreiben können folgende Befehle verwendet werden:
  $ value=65534

$ printf "%.8x" $value | xxd -r -p >data.bin

Was macht das printf und der Ausdruck %.8x?


Erklärung: 

`%x` bedeutet: Ausgabe als hexadezimale Zahl (Kleinbuchstaben).
`.8` bedeutet: mindestens 8 Stellen ausgeben; falls nötig, mit führenden Nullen auffüllen.

- Wie würdest du jemanden (mit einem Bash Grundverständnis) erklären wie diese Zeile die Aufgabenstellung löst.

Vorgang: Der Wert im Value wird von der Zeile in Hexadezimal umgewandelt, dann wird sie wieder in Binär umgewandelt und anschließend in die Datei geschrieben. 

- Finde einen Weg um den 4 Byte Binärwert aus der Datei wieder als Dezimalwert darzustellen. 

```sh
echo $((16#$(xxd -p data.bin)))

65534
```
-> Mit diesem Befehl ist es möglich den Binärwert wieder als Dezimalwert darzustellen
